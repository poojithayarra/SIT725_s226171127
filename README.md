# SIT725 6.1C - Testing Your Code

## Project Title

Student Grade Calculator API

## Description

This project demonstrates backend testing using Node.js, Express, Mocha and Chai.

The project contains two backend features:

1. A REST API endpoint for retrieving student information.
2. A calculation function for calculating student mark averages.

## Technologies

- Node.js
- Express
- Mocha
- Chai
- Supertest

## Running the Project

Install dependencies:

npm install

Start the server:

npm start

Run tests:

npm test

## Testing

The test suite covers:

- Valid REST API behaviour
- Invalid REST API behaviour
- Valid calculation behaviour
- Edge cases
- Invalid calculation input
